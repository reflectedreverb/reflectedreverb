# ReflectedReverb

Addons for World of Warcraft: Forever.

| Addon | What it does | Get it |
|---|---|---|
| **[RollFrames](https://github.com/reflectedreverb/RollFrames)** | Live group loot roll tracker: every Need, Greed and Pass, roll numbers and the winner, in a Blizzard-style window. | [CurseForge](https://www.curseforge.com/wow/addons/rollframes) · [Wago](https://addons.wago.io/addons/rollframes) |
| **[WorldSync](https://github.com/reflectedreverb/WorldSync)** | Know when your layer changes, and hop onto your group's layer in one click when the game offers a world refresh. | [CurseForge](https://www.curseforge.com/wow/addons/worldsync) · [Wago](https://addons.wago.io/addons/worldsync) |

Found a bug or have an idea? Open an issue on the addon's GitHub page.
